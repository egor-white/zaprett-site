# Использование подбора стратегий

1. В Хостах выберите один или несколько списков хостов, но главное, чтобы общий список не был слишком большим, следовательно нельзя использовать list-extended.txt и любые листы на его основе.

2. Зайдите в настройки, выберите пункт "Начать подбор"

3. Нажмите на кнопку сверху, начнётся перебор стратегий

4. После завершения подбора нажмите на галочку рядом с нужной стратегией, чтобы применить её.
